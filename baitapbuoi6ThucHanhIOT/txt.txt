6. Tổng hợp điều khiển đèn

Phần này tổng hợp toàn bộ hệ thống điều khiển đèn LED RGB thông qua giao thức MQTT, kết nối giữa ESP32, Backend (Spring Boot), và các ứng dụng Frontend (Web React, Mobile Flutter).

6.1. Tổng quan kiến trúc hệ thống

Hệ thống điều khiển đèn LED RGB sử dụng kiến trúc IoT với các thành phần chính:

1. ESP32: Thiết bị phần cứng điều khiển đèn LED RGB (NeoPixel)
2. MQTT Broker: Mosquitto broker làm trung gian truyền thông (10.30.233.17:1883)
3. Backend: Spring Boot với Eclipse Paho MQTT Client
4. Database: MySQL lưu trữ trạng thái và lịch sử
5. Frontend: 
   - Web (ReactJS + MQTT.js)
   - Mobile (Flutter + MQTT Client)

6.2. Luồng hoạt động

Luồng điều khiển đèn:
```
User (Web/App) → REST API → Backend → MQTT Publish → ESP32 → Thực thi → Publish trạng thái
                                                                              ↓
                                                                    Backend nhận & lưu DB
                                                                              ↓
                                                                    Web/App cập nhật UI
```

Chi tiết:
1. User thao tác trên giao diện (Web/App)
2. Frontend gửi HTTP request đến Backend hoặc publish trực tiếp qua MQTT
3. Backend nhận request và publish lệnh điều khiển lên topic `iot/demo/device/cmd`
4. ESP32 subscribe topic này, nhận lệnh và thực thi (thay đổi màu LED)
5. ESP32 publish trạng thái hiện tại lên topic `iot/demo/device/state`
6. Backend subscribe topic state, nhận và lưu vào database
7. Frontend cập nhật UI real-time qua MQTT hoặc polling REST API

Bước 5: Xử lý lệnh điều khiển từ MQTT

void handleDeviceCommand(char* topic, byte* payload, unsigned int length) {
  StaticJsonDocument<200> doc;
  DeserializationError err = deserializeJson(doc, payload, length);
  
  if (err) {
    Serial.println("❌ JSON parse error");
    return;
  }

  // Xử lý lệnh "light" (bật/tắt)
  if (doc.containsKey("light")) {
    String lightCmd = doc["light"].as<String>();
    if (lightCmd == "on") {
      applyColor(255, 255, 255);  // Bật đèn trắng
      publishDeviceState();
    } else if (lightCmd == "off") {
      applyColor(0, 0, 0);  // Tắt đèn
      publishDeviceState();
    }
  }
  
  // Xử lý lệnh "led_rgb" (thay đổi màu)
  else if (doc.containsKey("led_rgb")) {
    JsonArray arr = doc["led_rgb"].as<JsonArray>();
    if (arr.size() >= 3) {
      int r = arr[0];
      int g = arr[1];
      int b = arr[2];
      applyColor(r, g, b);
      publishDeviceState();
    }
  }
  
  // Xử lý lệnh "off" (backward compatibility)
  else if (doc.containsKey("off")) {
    if (doc["off"] == true) {
      applyColor(0, 0, 0);
      publishDeviceState();
    }
  }
}

deserializeJson(): Parse JSON từ byte array
doc.containsKey(): Kiểm tra key có tồn tại không
Lệnh "light": {"light": "on"} hoặc {"light": "off"}
Lệnh "led_rgb": {"led_rgb": [255, 0, 0]}
Lệnh "off": {"off": true}
Sau mỗi lệnh, gọi publishDeviceState() để cập nhật trạng thái lên broker

    public void init() {

        MqttConnectOptions opts = new MqttConnectOptions();
        opts.setAutomaticReconnect(true);
        opts.setCleanSession(true);
        client.connect(opts);
        
        client.setCallback(new MqttCallback() {
            @Override
            public void messageArrived(String topic, MqttMessage message) {
                String payload = new String(message.getPayload());
                
                // Lưu raw sensor data
                SensorData data = new SensorData(topic, payload, LocalDateTime.now());
                repository.save(data);
                
                // Parse và lưu device state

                    JsonNode json = objectMapper.readTree(payload);
                    if (json.has("led_rgb")) {

                        state.setDeviceId(extractDeviceId(topic));

                        state.setLedB(rgb.get(2).asInt());
                        state.setTimestamp(LocalDateTime.now());
                        deviceStateRepository.save(state);
                    }
                }
            }
        });
        
        client.subscribe(subscribeTopic, 1);
    }

@RestController
@RequestMapping("/api/v1")
@CrossOrigin(origins = "*")
public class IotController {
    private final MqttService mqttService;
    
    @Value("${mqtt.namespace:iot/demo}")
    private String namespace;
    
    // Điều khiển LED với RGB
    @PostMapping("/device/led/rgb")
    public ResponseEntity<?> setLedRgb(@RequestParam int r, 
                                       @RequestParam int g, 
                                       @RequestParam int b) {
        LedCommandRequest request = new LedCommandRequest(new int[]{r, g, b});
        String topic = namespace + "/device/cmd";
        String payload = objectMapper.writeValueAsString(request);
        mqttService.publish(topic, payload, 1, false);
        
        return ResponseEntity.ok().body(Map.of(
            "status", "LED color updated",
            "rgb", new int[]{r, g, b}
        ));
    }
    
    // Tắt LED
    @PostMapping("/device/led/off")
    public ResponseEntity<?> turnOffLed() {
        Map<String, Object> command = new HashMap<>();
        command.put("off", true);
        String topic = namespace + "/device/cmd";
        String payload = objectMapper.writeValueAsString(command);
        mqttService.publish(topic, payload, 1, false);
        
        return ResponseEntity.ok().body(Map.of("status", "LED turned off"));
    }
    
    // Lấy trạng thái hiện tại
    @GetMapping("/device/state")
    public ResponseEntity<?> getDeviceState(@RequestParam String deviceId) {
        DeviceState state = deviceStateRepository
            .findFirstByDeviceIdOrderByTimestampDesc(deviceId)
            .orElse(null);
        
        if (state == null) {
            return ResponseEntity.notFound().build();
        }
        
        DeviceStateResponse response = new DeviceStateResponse(
            state.getDeviceId(),
            new int[]{state.getLedR(), state.getLedG(), state.getLedB()},
            state.getTimestamp()
        );
        
        return ResponseEntity.ok(response);
    }
    
    // Lấy lịch sử
    @GetMapping("/device/state/history")
    public ResponseEntity<?> getStateHistory(@RequestParam String deviceId,
                                             @RequestParam(defaultValue = "50") int limit) {
        List<DeviceState> history = deviceStateRepository
            .findByDeviceIdOrderByTimestampDesc(deviceId)
            .stream()
            .limit(limit)
            .collect(Collectors.toList());
        
        return ResponseEntity.ok(history);
    }
}

export default function DeviceControls({ mqttClient, isConnected }) {
  const [lightOn, setLightOn] = useState(false);
  const [rgbValues, setRgbValues] = useState({ r: 0, g: 0, b: 0 });

  // Gửi lệnh qua MQTT
  const publishCommand = (command) => {
    if (!mqttClient || !isConnected) {
      alert('⚠️ Not connected to MQTT broker');
      return false;
    }

    const topic = 'iot/demo/device/cmd';
    const message = JSON.stringify(command);
    
    mqttClient.publish(topic, message, { qos: 0 }, (err) => {
      if (err) {
        console.error('❌ Publish error:', err);
      } else {
        console.log('✅ Command sent');
      }
    });
  };

  // Bật/tắt đèn
  const toggleLight = () => {
    const newState = !lightOn;
    setLightOn(newState);
    publishCommand({ light: newState ? 'on' : 'off' });
  };

  // Thay đổi màu RGB
  const updateRGB = (color, value) => {
    const newRgb = { ...rgbValues, [color]: parseInt(value) };
    setRgbValues(newRgb);
    publishCommand({ led_rgb: [newRgb.r, newRgb.g, newRgb.b] });
  };

  // Đặt màu preset
  const setPresetColor = (r, g, b) => {
    setRgbValues({ r, g, b });
    publishCommand({ led_rgb: [r, g, b] });
  };

  // Lắng nghe trạng thái từ ESP32
  useEffect(() => {
    if (!mqttClient) return;

    const handleMessage = (topic, message) => {
      if (topic === 'iot/demo/device/state') {
        const data = JSON.parse(message.toString());
        
        if (data.light !== undefined) {
          setLightOn(data.light === 'on');
        }
        
        if (data.led_rgb && Array.isArray(data.led_rgb)) {
          setRgbValues({
            r: data.led_rgb[0],
            g: data.led_rgb[1],
            b: data.led_rgb[2]
          });
        }
      }
    };

    mqttClient.on('message', handleMessage);
    
    return () => {
      mqttClient.removeListener('message', handleMessage);
    };
  }, [mqttClient]);

  return (
    <div>
      {/* Light On/Off Switch */}
      <button onClick={toggleLight}>
        {lightOn ? 'Turn OFF' : 'Turn ON'}
      </button>
      
      {/* RGB Sliders */}
      <input type="range" min="0" max="255" value={rgbValues.r}
        onChange={(e) => updateRGB('r', e.target.value)} />
      <input type="range" min="0" max="255" value={rgbValues.g}
        onChange={(e) => updateRGB('g', e.target.value)} />
      <input type="range" min="0" max="255" value={rgbValues.b}
        onChange={(e) => updateRGB('b', e.target.value)} />
      
      {/* Color Presets */}
      <button onClick={() => setPresetColor(255, 0, 0)}>Red</button>
      <button onClick={() => setPresetColor(0, 255, 0)}>Green</button>
      <button onClick={() => setPresetColor(0, 0, 255)}>Blue</button>
    </div>
  );
}

class MqttService {
  MqttClient? _client;
  
  Future<void> connect({required String broker, required int port}) async {
    _client = MqttServerClient.withPort(broker, 'flutter_client', port);
    _client!.keepAlivePeriod = 60;
    _client!.autoReconnect = true;
    
    final connMessage = MqttConnectMessage()
        .withClientIdentifier('flutter_iot_${DateTime.now().millisecondsSinceEpoch}')
        .startClean()
        .withWillQos(MqttQos.atMostOnce);
    
    _client!.connectionMessage = connMessage;
    
    await _client!.connect();
    
    if (_client!.connectionStatus!.state == MqttConnectionState.connected) {
      _client!.subscribe('iot/demo/device/state', MqttQos.atMostOnce);
      
      _client!.updates!.listen((List<MqttReceivedMessage<MqttMessage>> messages) {
        final msg = messages[0].payload as MqttPublishMessage;
        final payload = MqttPublishPayload.bytesToStringAsString(msg.payload.message);
        
        // Parse JSON và emit stream
        final data = jsonDecode(payload);
        _stateController.add(data);
      });
    }
  }
  
  void publishCommand(Map<String, dynamic> command) {
    final builder = MqttClientPayloadBuilder();
    builder.addString(jsonEncode(command));
    
    _client!.publishMessage(
      'iot/demo/device/cmd',
      MqttQos.atMostOnce,
      builder.payload!,
    );
  }
}

Hệ thống điều khiển đèn LED RGB hoàn chỉnh với các tính năng:

1. Điều khiển bật/tắt đèn
2. Thay đổi màu RGB (0-255 cho mỗi kênh)
3. Màu preset (Đỏ, Xanh lá, Xanh dương, vàng, tím, cam,...)
4. Real-time update trạng thái
5. Lưu lịch sử vào database
6. Hỗ trợ nhiều platform (Web, Mobile)
7. REST API và MQTT protocol
8. Auto-reconnect khi mất kết nối

Công nghệ sử dụng:
- ESP32: C++ với Arduino framework
- Backend: Java Spring Boot + Eclipse Paho MQTT
- Database: MySQL
- Web: ReactJS + MQTT.js
- Mobile: Flutter + MQTT Client
- Broker: Mosquitto MQTT

- Real-time communication qua MQTT
- Scalable architecture
- Cross-platform support
- RESTful API cho integration
